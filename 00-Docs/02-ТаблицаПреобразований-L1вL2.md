# Таблица преобразований L1 -> L2

| Workflow | L1 -> L2 | Обязательные поля | Правило уточнения | Примеры фраз |
|---|---|---|---|---|
| Вода | «выпил воду» -> `ПриёмВоды` | `объём_мл`, `время` | Если нет объёма, спросить «Сколько мл?»; если нет времени — «Записать на сейчас?» | «Выпил 300 мл воды», «Запиши стакан воды» |
| Стресс | «мне стрессово» -> `СтрессСобытие` | `интенсивность_1_10`, `причина`, `время_начала` | Если нет интенсивности, запросить шкалу 1–10 | «Стресс на 8 из-за дедлайна», «Я нервничаю после встречи» |
| Настроение | «настроение хорошее» -> `ЗаписьНастроения` | `оценка_1_10`, `время` | Если дана только эмоция, предложить оценку числом | «Настроение на 7», «Сегодня подавлен» |
| Сон | «лег/проснулся» -> `СессияСна` | `время_начала`, `время_окончания` | При одном маркере времени уточнить второй позже или записать открытую сессию | «Лёг в 23:40», «Проснулся в 07:10» |
| Питание | «поел» -> `ЗаписьПитания` | `тип_приёма`, `время` | Если нет состава, запросить краткий список продуктов | «Обед: гречка и курица», «Перекусил яблоком» |
| Тренировка | «тренировка» -> `СессияТренировки` | `тип`, `длительность_мин` | Если нет длительности, спросить минуты; если нет типа, спросить формат | «Бег 35 минут», «Силовая тренировка 50 мин» |
| Задача: создать | «создай задачу» -> `Задача` | `название`, `статус=новая` | Если нет срока/приоритета — предложить добавить | «Создай задачу: отправить КП», «Поставь задачу на завтра» |
| Задача: закрыть | «закрой задачу» -> обновление `Задача` | `id`/`название`, `статус=закрыта` | При неоднозначности показать список совпадений | «Закрой задачу отчёт», «Отметь выполненной задачу #42» |
| Задача: список | «покажи задачи» -> `СписокЗадач` | `фильтр` (опц.) | Если фильтр не указан, вернуть активные на сегодня | «Список задач на сегодня», «Покажи просроченные» |
| Помодоро: старт | «старт помодоро» -> `СессияПомодоро` (open) | `время_старта` | Если не указана задача, предложить привязать | «Запусти помодоро», «Старт помодоро по задаче презентация» |
| Помодоро: стоп | «стоп помодоро» -> обновление `СессияПомодоро` | `время_остановки`, `статус` | Если нет активной сессии — сообщить и предложить создать запись вручную | «Останови помодоро», «Стоп, сессия завершена» |
| Клиент: добавить | «добавь клиента» -> `Клиент` | `имя` | Если нет контактов, спросить телефон/email | «Добавь клиента Иван Петров», «Новый клиент ООО Вектор» |
| Клиент: оплата | «оплата от клиента» -> `Оплата` + update `Сделка` | `клиент_id`, `сумма`, `дата` | Если клиент не найден, предложить выбор/создание | «Пришла оплата 50 000 от Альфа», «Оплачен счёт клиента Вектор» |
| Клиент: карточка | «покажи карточку клиента» -> чтение `Клиент` | `клиент_id`/`имя` | При нескольких совпадениях уточнить компанию | «Открой карточку клиента Романов», «Покажи клиента ООО Орбита» |
| Отчёт за день | «отчёт за день» -> `ОтчётДня` | `дата` | Если дата не указана, использовать текущую | «Сделай отчёт за сегодня», «Отчёт за 12.02» |
