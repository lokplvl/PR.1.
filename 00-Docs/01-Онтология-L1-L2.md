# Онтология L1-L2

## L1: Реальные события

### Здоровье
- Выпил воду.
- Поел/перекусил.
- Начал тренировку.
- Завершил тренировку.
- Лёг спать.
- Проснулся.
- Измерил вес/пульс/давление.

### Психика
- Почувствовал стресс.
- Зафиксировал настроение.
- Выполнил дыхательную/восстановительную практику.
- Отметил триггер тревоги.

### Продуктивность
- Начал помодоро.
- Остановил помодоро.
- Создал задачу.
- Закрыл задачу.
- Запросил список задач.

### CRM
- Добавил клиента.
- Обновил карточку клиента.
- Создал сделку.
- Сменил стадию сделки.
- Отметил оплату по сделке.

### Управление
- Запросил отчёт за день.
- Поставил цель.
- Обновил приоритет цели.
- Принял решение по плану дня.
