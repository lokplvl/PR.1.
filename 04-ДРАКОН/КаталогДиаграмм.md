## Текстовая канва основных диаграмм (стиль ДРАКОН)

> Формат: **Старт -> Действие -> Вопрос? (Да/Нет ветки) -> Конец**

### 1) ОбработкаКоманды
- Старт -> Принять фразу пользователя и время -> Команда распознана?  
  - Да -> Определить интенцию и обязательные поля -> Полей достаточно?  
    - Да -> Передать в целевой workflow -> Сформировать ответ -> Конец.  
    - Нет -> Задать уточняющий вопрос -> Получить уточнение -> Передать в workflow -> Сформировать ответ -> Конец.  
  - Нет -> Вернуть сообщение «Не понял команду» -> Конец.

### 2) ЗаписатьВоду
- Старт -> Извлечь объём воды и время -> Объём найден?  
  - Да -> Создать запись события воды -> Обновить дневную сумму воды -> Вернуть подтверждение -> Конец.  
  - Нет -> Задать вопрос «Сколько мл воды записать?» -> Получить объём -> Создать запись события воды -> Вернуть подтверждение -> Конец.

### 3) ПоказатьВодуЗаДень
- Старт -> Определить дату отчёта (сегодня/указанная) -> Дата корректна?  
  - Да -> Рассчитать сумму воды за день -> Вернуть итог в мл -> Конец.  
  - Нет -> Запросить дату в формате ДД.ММ -> Получить дату -> Рассчитать сумму -> Вернуть итог -> Конец.

### 4) ЗаписатьСтресс
- Старт -> Извлечь интенсивность, причину и статус -> Это завершение стресса?  
  - Да -> Записать событие завершения стресса -> Вернуть подтверждение -> Конец.  
  - Нет -> Интенсивность указана?  
    - Да -> Записать стресс с интенсивностью и причиной -> Вернуть подтверждение -> Конец.  
    - Нет -> Задать вопрос «Оцените стресс от 1 до 10» -> Получить оценку -> Записать стресс -> Вернуть подтверждение -> Конец.

### 5) ЗаписатьНастроение
- Старт -> Извлечь оценку и эмоциональный маркер -> Оценка указана?  
  - Да -> Записать настроение -> Вернуть подтверждение -> Конец.  
  - Нет -> Задать вопрос «Оцените настроение по шкале от 1 до 10» -> Получить оценку -> Записать настроение -> Вернуть подтверждение -> Конец.

### 6) ЗаписатьСон
- Старт -> Извлечь время начала, время окончания, длительность, качество -> Есть хотя бы один валидный параметр сна?  
  - Да -> Записать событие сна -> Это начало сна?  
    - Да -> Вернуть «Зафиксировал начало сна» -> Конец.  
    - Нет -> Это окончание сна?  
      - Да -> Вернуть «Сон закрыт» -> Конец.  
      - Нет -> Вернуть «Сон записан» -> Конец.  
  - Нет -> Задать вопрос «Когда легли и проснулись?» -> Получить уточнение -> Записать сон -> Вернуть подтверждение -> Конец.

### 7) ЗаписатьПитание
- Старт -> Извлечь тип приёма пищи, состав, ккал -> Тип или состав найден?  
  - Да -> Записать событие питания -> Вернуть подтверждение по типу приёма пищи -> Конец.  
  - Нет -> Задать вопрос «Что именно съели?» -> Получить уточнение -> Записать питание -> Вернуть подтверждение -> Конец.

### 8) ЗаписатьТренировку
- Старт -> Извлечь тип тренировки, длительность, нагрузку -> Длительность указана?  
  - Да -> Записать тренировку -> Вернуть подтверждение -> Конец.  
  - Нет -> Задать вопрос «Сколько минут длилась тренировка?» -> Получить длительность -> Записать тренировку -> Вернуть подтверждение -> Конец.

### 9) СоздатьЗадачу
- Старт -> Извлечь название, приоритет, срок -> Название задачи указано?  
  - Да -> Создать запись в таблице задач -> Записать событие создания задачи -> Вернуть подтверждение -> Конец.  
  - Нет -> Задать вопрос «Как назвать задачу?» -> Получить название -> Создать задачу -> Вернуть подтверждение -> Конец.

### 10) ЗакрытьЗадачу
- Старт -> Извлечь `задача_id` или название -> Идентификатор или название получены?  
  - Да -> Найти задачу -> Задача найдена?  
    - Да -> Обновить статус на «закрыта» -> Записать событие закрытия -> Вернуть подтверждение -> Конец.  
    - Нет -> Вернуть «Задача не найдена» -> Конец.  
  - Нет -> Задать вопрос «Какую задачу закрыть: номер или название?» -> Получить уточнение -> Найти и закрыть задачу -> Вернуть подтверждение -> Конец.

### 11) НачатьПомодоро
- Старт -> Извлечь параметры работы/отдыха и задачу -> Есть активная помодоро-сессия?  
  - Да -> Вернуть «Сессия уже активна» -> Конец.  
  - Нет -> Параметры указаны явно?  
    - Да -> Создать активную сессию с указанными параметрами -> Записать событие старта -> Вернуть подтверждение -> Конец.  
    - Нет -> Применить параметры по умолчанию (25/5) -> Создать сессию -> Записать событие -> Вернуть подтверждение -> Конец.

### 12) ОтчётЗаДень
- Старт -> Определить дату отчёта и фокус -> Дата корректна?  
  - Да -> Собрать метрики (вода, стресс, помодоро, задачи, CRM) -> Рассчитать индекс дня -> Сохранить отчёт дня -> Вернуть сводку -> Конец.  
  - Нет -> Задать вопрос по формату даты -> Получить корректную дату -> Собрать метрики -> Сохранить и вернуть сводку -> Конец.
