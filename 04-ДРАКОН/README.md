# ДРАКОН: правила уровня 4

## Базовое правило
**Уровень 4 = диаграммы, источник истины.**

Если текстовая спецификация и диаграмма расходятся, приоритет у диаграммы уровня 4. Любые изменения workflow сначала вносятся в диаграмму, затем синхронизируются в документацию и реализации.

## Именование
- Имена шагов — только на русском языке.
- Имена веток — только на русском языке.
- Служебные термины допустимы только при отсутствии русского эквивалента.

## Практика
1. Одна диаграмма = один главный workflow.
2. Все развилки содержат явный критерий (да/нет, найдено/не найдено, достаточно/недостаточно данных).
3. Каждый термин диаграммы должен совпадать с доменным словарём L2.
