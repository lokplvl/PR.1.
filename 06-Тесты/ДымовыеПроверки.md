# Дымовые проверки (ручной чек-лист)

1. Команда на русском языке распознаётся без переключения локали.
2. Для воды без объёма система задаёт уточняющий вопрос.
3. Для стресса без интенсивности система запрашивает шкалу 1–10.
4. Начало и завершение сна создают/закрывают одну сессию сна.
5. Питание сохраняется с типом приёма и временем.
6. Тренировка без длительности требует уточнение.
7. Создание задачи без названия невозможно (обязательное уточнение).
8. Закрытие задачи обновляет статус, а не создаёт новую запись.
9. Список задач по умолчанию показывает активные задачи на сегодня.
10. Старт помодоро невозможен при уже активной сессии.
11. Стоп помодоро без активной сессии даёт корректное сообщение.
12. Добавление клиента создаёт карточку с русскими полями.
13. Отметка оплаты обновляет оплату и связанный статус сделки.
14. Отчёт за день агрегирует минимум: вода, сон, стресс, помодоро, задачи.
15. Все ответы ассистента формулируются на русском доменном языке.
